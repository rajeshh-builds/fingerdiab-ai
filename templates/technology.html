01

Grayscale Optical Normalization

Color Dimension Flattening • 8-Bit Luminance Channel

The input RGB or RGBA optical image is converted to single-channel 8-bit luminance using ITU-R 601-2 luma coefficients ($Y = 0.299R + 0.587G + 0.114B$). High-frequency noise is suppressed using a Gaussian blur kernel ($k=5$) while preserving epidermal boundary gradients.

02

CLAHE (Contrast Limited Adaptive Histogram Equalization)

Sub-Tile Local Dynamic Range Amplification

Local illumination variances caused by uneven sensor contact are mitigated by dividing the image into $8 \times 8$ contextual tiles. Contrast amplification is capped at a clip limit of $2.0$ to prevent optical grain amplification while enhancing faint dermatoglyphic ridge valleys.

03

Adaptive Gaussian Binarization & Valley Isolation

Dynamic Threshold Segmentation • Zero Hardcoding

Each pixel's threshold is calculated as a weighted Gaussian sum over its $11 \times 11$ neighborhood minus constant $C=2$. This cleanly isolates foreground epidermal ridges ($1$) from background dermal furrows ($0$), unaffected by global sensor exposure inconsistencies.

04

Zhang-Suen Morphological Skeletonization

Medial Axis Ridge Thinning • 1-Pixel Topological Network

The iterative two-pass Zhang-Suen thinning algorithm erodes ridge contours while preserving topological connectivity, resulting in a single-pixel wide skeleton network suitable for accurate ridge count and minutiae intersection detection.

05

Minutiae Extraction & Crossing Number (CN)

Rutovitz Topology Parsing • Pattern Archetype Classification

Using 8-neighborhood Rutovitz crossing numbers, the system localizes ridge terminations (CN = 1) and bifurcations (CN = 3). Combined with contour curvature profiles, it classifies pattern archetypes (Arch, Loop, or Whorl) with calibrated feature confidence.
